How to install on Windows
  1. Click Windows installer above and wait for the download to finish.
  2. Open the file from your Downloads folder.
  3. If Windows shows a blue "Windows protected your PC" box, click More info, then Run anyway.
  4. Follow the installer, then open QPackageTracker from the Start menu.
Ubuntu and Debian (.deb) Recommended Ubuntu 22.04 or newer, Debian 12 or newer. Updates install from inside the app. AppImage A single file that runs on most other Linux systems. Flatpak Sandboxed, for any system with Flatpak. Snap Sandboxed, for systems with Snap.
How to install on Linux

.deb: double-click the file to open it in your software center, or run:

sudo apt install ./QPackageTracker_*_amd64.deb

AppImage: right-click the file, choose Properties > Permissions, tick Allow executing as program, then double-click it. Or run:

chmod +x QPackageTracker-*-x86_64.AppImage && ./QPackageTracker-*-x86_64.AppImage

Flatpak:

flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
flatpak install --user ./QPackageTracker-*-x86_64.flatpak

Snap:

sudo snap install --dangerous ./QPackageTracker_*_amd64.snap

All Linux versions are 64-bit. Tray features need a system tray, which some desktops turn on with an extension.

Questions

Is it really free?

Yes, for personal use. You can track up to 10 packages at a time with USPS, for as long as you like, and you get every update. A Business license adds more carriers, unlimited packages and ways to notify other people.

Do I need to create an account?

Not with us. To get tracking information you connect a free USPS Business account (or a Trace API account), and the setup guide walks you through it with pictures.

Where does my information go?

Your packages, notes and history are saved on your computer. Tracking numbers are only sent to the tracking service you choose, so it can look them up. There is no advertising, analytics or crash reporting. Full privacy details.

Does it work on a Mac, phone or tablet?

QPackageTracker runs on Windows and Linux computers.

Windows warned me about the installer. Is it safe?

Windows sometimes warns about apps it hasn't seen often. If you downloaded the installer from this page, click More info and then Run anyway. Every release is also signed, and the app checks its own files each time it starts.

How do I update?

The app checks once a day and tells you when a new version is ready. Click Install and it does the rest. Your packages and settings are kept.

I bought Business. How do I use my key?

Open QPackageTracker and go to Help > License..., then enter your key. One license covers one computer. To move it to a new computer, reset it in the license portal and enter it there. If your license ever lapses, nothing is deleted.

How do I get help?

Email support@quynnsoftware.com. It helps to include the version number from Help > About.
